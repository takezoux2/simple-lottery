# フラッシュカード演出時間・減速調整仕様書

本仕様書は、Simple Lottery における「フラッシュカード（文字切り替え）」演出の抽選時間およびアニメーションの減速（イージング）演出の機能設計と実装方針を定義します。

---

## 1. 概要と目的

- **抽選時間の調整**: フラッシュカード演出の抽選時間を約3秒間（3000ms）に設定し、くじ引きのドキドキ感・演出感を向上させる。
- **減速（イージング）アニメーション**: 最初は高速（約50ms間隔）で文字が切り替わり、時間が経つにつれて徐々に各ラベルの表示時間（ディレイ）が伸びて減速し、3秒経過時に最終結果でピタッと止まる演出を実現する。

---

## 2. アニメーション・動作仕様

### 2.1 タイミング制御

- **全体時間 (`TOTAL_DURATION`)**: 3000ms (3秒)
- **初期間隔 (`MIN_DELAY`)**: 50ms
- **終了直前間隔 (`MAX_DELAY`)**: 450ms
- **進行計算**:
  - 経過時間割合: $p = \min(1.0, \text{elapsed} / \text{TOTAL_DURATION})$
  - 各ステップ遅延: $\text{currentDelay} = \text{MIN\_DELAY} + (\text{MAX\_DELAY} - \text{MIN\_DELAY}) \times p^{1.8}$
- **項目の切り替え**:
  - 回転中は直前の表示項目と重複しないようランダムに選定（項目数が2以上の場合）。
  - 経過時間が3000msに到達した最終ステップで、確率に基づいて決定された当選結果（`finalResult`）を表示・確定。

### 2.2 状態管理と後処理

- 抽選開始時: `isDrawing = true`、ボタン無効化。
- 抽選完了時: `currentResult` に当選結果を設定、履歴（`addHistoryItem`）および当選数カウント（`incrementHitCount`）を更新し、`isDrawing = false`。
- アンマウントや多重実行の防止処理。
