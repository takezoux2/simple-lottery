# 確率設定画面 仕様書

本仕様書は、Simple Lottery における「確率設定画面」の機能設計、データ構造、UI/UX 要件、および実装方針を定義します。

---

## 1. 概要と目的

ユーザーがくじ引きの項目（ラベル）とそれぞれの出現比重を自由にカスタマイズできるようにします。
比重変更に伴いリアルタイムに確率（%）を可視化し、複数の設定（プリセット）を LocalStorage に保存・切り替え・編集・複製できるようにします。

---

## 2. 仕様確定事項

ユーザーヒアリングにより以下の仕様を確定しました：

1. **メイン画面の演出・履歴集計**:
   - 各項目を汎用的な選択肢として扱い、項目ごとのカラーやラベルを表示。
   - 履歴も項目別の出現回数・割合を集計表示。
2. **画面遷移・UI構造**:
   - `/settings` ページ内で「一覧（List）」「新規作成（Create）」「編集（Edit）」をスムーズに切り替える構成。
3. **比重（ウェイト）の入力仕様**:
   - **正の整数（1以上の整数: 1, 2, 5, 10...）** のみに制限（ステップ操作や直感的な入力に対応）。
4. **項目カラー設定**:
   - プリセットカラーパレット（Indigo, Emerald, Amber, Rose, Sky, Violet, Orange, Teal 等）から選択可能。新規追加時は自動で色を割り当て。

---

## 3. 機能要件

### 3.1 確率のリアルタイム計算
- 項目ごとに「ラベル（文字列）」「比重（1以上の正の整数）」「カラー（HEX）」を設定。
- 項目全体の比重合計 $\sum W_i$ に対する各項目の比率 $\frac{W_i}{\sum W_i} \times 100$ を算出し、リアルタイムに「XX.X%」として表示。
- 全体の確率分布を視覚的に把握できるカラープログレスバー / 分布プレビューを配置。

### 3.2 LocalStorage 永続化と複数設定の管理
- 複数の確率設定（プリセット）を LocalStorage に保存（キー: `simple_lottery_configs_v1`）。
- 現在選択されているアクティブな設定 ID を保持（キー: `simple_lottery_active_id_v1`）。
- 初期起動時は標準的なデフォルトプリセット（「スタンダードくじ (2択)」「おみくじ (5択)」「サイコロ (6択)」）を提供。
- 各設定の「アクティブ化」「編集」「複製」「削除」操作を提供（最後の1件は削除不可などの安全策を導入）。

### 3.3 画面構成
1. **設定一覧画面 (`/settings` - list mode)**:
   - 保存済み設定一覧カード（設定名、項目数、更新日時、確率分布カラーバー）。
   - 「現在使用中」バッジと「この設定を使う」切り替え。
   - 「編集」「複製」「削除」アクション。
   - 「新規作成」ボタン、メイン画面へ戻るリンク。
2. **新規作成 / 編集画面 (`/settings` - create / edit mode)**:
   - 設定名入力。
   - 項目一覧エディタ（カラー選択、ラベル入力、比重ステッパー / 数値入力、削除ボタン）。
   - 「+ 項目を追加」ボタン。
   - リアルタイム確率（%）表示およびカラー分布プレビューバー。
   - バリデーション（設定名必須、2項目以上、各比重1以上）。
   - 「保存する」「保存して適用する」「キャンセル」ボタン。

### 3.4 メイン画面連携 (`/`)
- LocalStorage からアクティブな設定を読み込んでくじ引きを実行。
- 上部に設定切り替えドロップダウン/クイック切替と「設定管理」リンクを配置。
- 抽選結果・履歴は各項目の色やラベルに応じたデザインで表示。

## 4. データ構造

```typescript
export interface LotteryItem {
  id: string;
  label: string;
  ratio: number; // 正の整数 (1, 2, 3...)
  color: string; // 例: '#4f46e5'
}

export interface LotteryConfig {
  id: string;
  name: string;
  items: LotteryItem[];
  createdAt: number;
  updatedAt: number;
}
```
