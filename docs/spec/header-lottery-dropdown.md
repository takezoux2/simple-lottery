# ヘッダー改善（PWA/SSGバッジ削除・抽選種類ドロップダウン移行）仕様書

本仕様書は、Simple Lottery におけるヘッダーUIの整理、PWA/SSGバッジの削除、および抽選種類（くじ設定）の切り替えUIをヘッダーへドロップダウン形式で統合する機能設計と実装方針を定義します。

---

## 1. 概要と目的

- **PWA / SSG バッジの削除**: ヘッダーのロゴ横に配置されていた「PWA / SSG」バッジを削除し、ヘッダー領域をすっきりさせ、主要な操作コントロールのためのスペースを確保する。
- **抽選種類のドロップダウン移行**: これまでメインコンテンツ上部の「Preset Switcher Bar」に横並びボタンとして配置されていたくじ設定（プリセット）の選択UIを、ヘッダー内のドロップダウンリスト（`<select>`）に集約・移動する。
- **UI/UXの向上**: メイン画面の縦スペースを有効活用し、スマートフォンやPCなど各種画面幅においてスムーズにくじ種類の切り替えと設定アクセスを行えるようにする。

---

## 2. 画面・UI仕様

### 2.1 ヘッダー (`src/app/page.tsx`)

- **ロゴ**: 「Simple Lottery」テキスト（グラデーション）。
- **PWA / SSG バッジ**: 削除。
- **抽選種類ドロップダウン (`<select>`)**:
  - ヘッダー右側に配置。
  - 現在アクティブなくじ設定（`activeConfig.id`）を選択状態として保持。
  - 選択肢（`<option>`）には各設定のアニメーションアイコン（🎡 または 🎴）と設定名（`cfg.name`）を表示。
  - 変更時に既存の `handleSelectConfig(id)` を呼び出し、アクティブ設定・当選履歴・当選数カウントをシームレスに切り替える。
  - スタイリング: Tailwind CSS による角丸、背景色、枠線、フォーカスリング、カスタム下向き矢印アイコン、ダークモード対応。
  - レスポンシブ: スマートフォン表示時にも折り返さずにコンパクトに収まるよう `max-w` やフォントサイズを調整。
- **確率設定リンク**:
  - ドロップダウンの横に配置。
  - アイコン＋「確率設定」リンクボタン。

### 2.2 メインコンテンツ (`src/app/page.tsx`)

- これまでメインコンテンツの先頭に存在していた「Preset Switcher Bar」を削除。
- 抽選メインカードが上部にすっきりと配置され、ファーストビューでの操作性が向上。

---

## 3. テスト・品質保証方針

- `pnpm test` (vitest): 既存のユニットテスト（storage, lottery）が全件パスすることを確認。
- `pnpm lint` / `pnpm lint:fix` (biome): コードフォーマット・リントエラーがないことを確認。
- `pnpm build`: Next.jsの静的エクスポートビルドが正常に完了することを確認。
